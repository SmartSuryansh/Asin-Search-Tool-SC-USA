# ASIN Decision Engine

Search any ASIN → tier badge, verdict (scale/fix/launch/…), stock & listing status,
campaigns/portfolios, ad metrics and a suggested reply. Batch mode accepts a pasted list.

## Host it on GitHub Pages (free public link)
1. Create a **new public repository** (e.g. `asin-decision-engine`).
2. **Add file → Upload files** → upload `index.html`, `data.json`, `README.md` → **Commit**.
3. **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main` , folder `/ (root)` → **Save**.
4. Wait ~1 minute → your link appears at the top of the Pages settings:
   `https://<your-username>.github.io/asin-decision-engine/`

Keep `index.html` and `data.json` in the **same folder**. To refresh the data later,
just replace `data.json` and commit.

Data window: Listings Sep 10 2026 · Ads & Sales Jan–Aug 2026 (with 2025 for YoY).
